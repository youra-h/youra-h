## Основной проект: soldy

[soldy](https://github.com/youra-h/soldy) — open-source фреймворк headless UI-компонентов: поведение компонентов и семантика WAI-ARIA пишутся один раз в ядре на TypeScript, не зависящем от фреймворка, а каждый UI-фреймворк получает тонкий адаптер. Автор и архитектор; ~1 400 коммитов, ~590 файлов тестов.

**Стек:** TypeScript, React, Vue 3, Angular, Svelte, Solid, Web Components, Vite, Vitest, Playwright, Tailwind (пакет темы), ESLint, changesets, GitHub Actions.

**Что спроектировал и сделал**

- **Слоистая архитектура.** `core` (headless-модели) → `plugins` (работа с DOM и жизненный цикл) → `setup` (общие дескрипторы компонентов и проводка) → адаптеры `ui/*`. Импорты фреймворков разрешены только в адаптерах — это стерегут правила ESLint и тесты.
- **Компоненты:** Button, Input, Checkbox, Switch, RadioGroup, Tabs, Accordion, ListBox, Select, Tags, Slider, Popover, Tooltip, Dialog, Drawer, Calendar, DatePicker, Table и другие, с составными частями (`Tabs.Item`, `Tabs.Content`).
- **Движок коллекций:** один движок для всех списочных компонентов, с подключаемыми расширениями выбора, активации, порядка и drag-and-drop, и фасады, которые отдают их компонентам.
- **Доступность:** паттерны WAI-ARIA, клавиатурная навигация, управление фокусом, доступные имена; id строятся от монтирования, поэтому разметка безопасна для SSR.
- **Оверлеи:** слои, привязка к якорю, закрытие по клику мимо, ловушка фокуса и блокировка прокрутки — общие для Select, Popover, Dialog и Drawer.
- **Темы:** компоненты отдают только BEM-классы и `data-*` атрибуты; тема — отдельный пакет. Локализация через провайдер локали поддерева; анимации следуют `prefers-reduced-motion`.
- **Проверки в CI:** типы по каждому пакету (включая Angular `ngc` со строгими шаблонами), правила линтера, запрещающие приведения типов, тесты раскладки в настоящем Chromium и проверка, что опубликованные пакеты объявляют всё, что импортируют.
- **Разработка с AI-агентами:** агенты-аналитик, тимлид, программист и дизайнер работают через доску задач по строгим инструкциям проекта ([AGENTS.md](https://github.com/youra-h/soldy/blob/main/AGENTS.md)).

## Бенчмарк таблицы: 5 000 строк × 20 колонок

Таблица soldy теперь опережает все библиотеки компонентов Vue по рендеру, памяти, выделению, сортировке и замене данных; headless-ориентиры без клавиатуры, ARIA и ресайза колонок остаются легче. За день профилирования первый рендер сократился с 2,9 до 1,58 с, память — с 729 до 288 МБ, «выделить все» — с 1,7 до 0,62 с. [Стенд замеров](https://github.com/youra-h/soldy/tree/main/tools/bench-table) (Vite + Playwright) сделал сам, чтобы искать узкие места; каждая оптимизация записана в [BENCHMARKS.md](https://github.com/youra-h/soldy/blob/main/BENCHMARKS.md).

Методика: Vue 3.5, продакшн-сборка, Chromium, медиана 3 прогонов, настоящие клики в DOM, время — до успокоения кадров. Память — JS-куча после рендера. Виртуализация выключена; каждый прогон проверяется (5 000 → 0 выделенных строк, верный порядок сортировки).
